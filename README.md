# 🛡 StacksShield Security IDE

AI-powered smart contract security IDE for Clarity contracts.

---

## 🚀 Features

- Smart contract bug detection
- Auto-fix broken Clarity code
- Monaco Editor integration
- Live contract preview

---

## 🛠 How to use

1. Paste your contract in the editor  
2. Click **Auto-Fix Contract**  
3. Get cleaned secure code instantly
